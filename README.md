
# Overview

This is a certification project used to improve my skills on becoming a data analyst.

# Objectives

- Create and manage a relational database for World Cup match results using PostgreSQL.
- Import match data from a CSV file into relational database tables.
- Prevent duplicate team records by checking whether teams already exist before inserting them.
- Establish relationships between teams and games using primary keys and foreign keys.
- Automate database population using Bash scripting and PostgreSQL commands.
- Analyze World Cup match results using SQL aggregate functions and filtering.
- Retrieve tournament statistics, including total goals, average goals, highest-scoring games, and championship winners.
- Query historical match data by year, tournament round, and team name.

# Tools I Used

- **SQL:** Used to build the database, insert values, and add appropriate data types and constraints
- **PostgreSQL:** Used to execute SQL queries and perform data analysis.
- **Bash:** Used to make scripts for inserting data to database and execute SQL queries
- **Visual Studio Code:** Used to write and organize SQL queries.
- **Git:** Used for version control to track changes and manage the project during development.
- **GitHub:** Used to store and document the project.
